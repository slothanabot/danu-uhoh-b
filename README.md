One word an agent says when it has no idea what to do: **hallucinating**.

When an agent is lost, the honest confession is that it is hallucinating —
making things up instead of knowing. It is the agent-native failure mode,
funny on its own, and fresher than the obvious "uh-oh" / "oops" / "hmm".
